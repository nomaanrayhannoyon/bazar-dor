
# 🛒 বাজার দর | BazarDor

### Smart Daily Market Price Tracker for Bangladesh 🇧🇩

## 📌 About the Project

**BazarDor** is a web application designed to help people in Bangladesh easily track the prices of daily essential products. It provides current product prices, price increase and decrease information, category-based browsing, and detailed product information in one place.

The main goal of this project is to make daily market price information more accessible and help users make informed shopping decisions.

## ✨ Key Features

- 📊 **Product Price Tracking** — View prices of essential products.
- 📈 **Price Change Monitoring** — Identify products with increasing or decreasing prices.
- 🗂️ **Category Filtering** — Browse products by category.
- 🔎 **Product Details** — Explore detailed product information and market prices.
- 🔐 **Secure Authentication** — Sign up and sign in using Better Auth.
- 🌐 **Social Login** — Sign in with Google and GitHub.
- 🛡️ **Protected Routes** — Restrict access to pages that require authentication.
- 👤 **User Profile** — Manage user information.
- 📱 **Responsive Design** — Enjoy a consistent experience across mobile, tablet, and desktop devices.
- ⏳ **Loading States & Notifications** — Get feedback while data loads and when actions succeed or fail.

## 🛠️ Technologies Used

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS
- **Authentication:** Better Auth
- **Notifications:** React Hot Toast
- **Data:** REST API
- **Version Control:** Git & GitHub

## 🎯 Project Goal

The goal of BazarDor is to make essential product price information easier to access through a simple, user-friendly, and responsive interface. The project also demonstrates practical skills in modern web development, API integration, authentication, and dynamic routing.
